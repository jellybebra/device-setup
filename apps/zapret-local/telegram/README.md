# Telegram через Zapret Local

Локальный MTProto-мост на базе [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy)
(`307a384ab7f522e34bb1a045884d0bd90f40bee5`). Telegram Desktop подключается
к нему вместо заблокированных TCP-адресов DC. Все исходящие WebSocket, HTTP/2
и резервные TCP-соединения мост передаёт в SOCKS Zapret Local, который
использует физический интерфейс. При недоступном Zapret прямого выхода или
переключения на VPN нет.

DC2/DC4 используют официальный WebSocket через `149.154.167.220`. Для остальных
DC и некоторых медиа upstream использует внешние CF-ретрансляторы из своего
закреплённого списка. Это не полностью автономный обход: внешние ретрансляторы
могут видеть IP и метаданные соединения, но MTProto-содержимое остаётся
зашифрованным Telegram. Свои ключи аккаунта или сессии мосту не передаются.
Список закреплён вместе с исходниками, фоновые загрузки списка отключены.
TLS проверяет сертификат и имя хоста, fronting с отключённой проверкой имени
не используется.

## Использование

Мост, интерпретатор Python, криптографические библиотеки и корневые сертификаты
встроены в `.app` и DMG. Python/Homebrew и отдельный установщик пользователю
не нужны. Включи Zapret Local и нажми **Подключить Telegram**. Приложение
откроет локальную ссылку `tg://proxy`; Telegram попросит включить этот прокси.
По умолчанию новая установка слушает `127.0.0.1:44950` (вне диапазона
автоматических исходящих портов macOS), при первой установке занятого
порта выбирает свободный. Ключ генерируется локально через Security.framework.

Встроенный мост запускается только вместе с SOCKS Zapret. Выключение, смена
порта и выход из приложения останавливают дочерний процесс. Закрытие канала
владельца при аварийном завершении приложения также останавливает мост.
Приложение проверяет готовность слушателя по PID и порту и перезапускает
завершившийся процесс с задержкой 10 секунд. Статус **Готов** означает
готовность локального прокси, а не проверку связи со всеми DC Telegram.

Состояние: `~/Library/Application Support/com.jellybebra.zapret-local/telegram/`.
`settings.json` с локальными `port` и `secret` доступен только владельцу.
При обновлении прежней отдельной установки приложение сохраняет порт и ключ,
останавливает только известный LaunchAgent `com.jellybebra.zapret-local.telegram`
и переносит его plist в `legacy-launch-agent.plist.disabled`. Старый каталог
`Zapret Local Telegram` остаётся резервной копией и больше не запускается.
Действующая настройка Telegram Desktop продолжает работать без повторного ввода.

Автозапуск один — **Запускать при входе** в Zapret Local. Мост не имеет
отдельного LaunchAgent и не загружает зависимости при запуске.
Настройка не распространяется на Telegram Web, HTTPS-ссылки `t.me` и звонки:
их нужно проверять отдельно.

## Сборка

`npm run build` собирает также транспорт через `telegram/build.py`:
закреплённый upstream, зависимости из `build-requirements.txt`, PyInstaller
onedir и встроенные лицензии. Нужен Python 3.12+ только на сборочной машине.
`ZAPRET_TG_SOURCE` позволяет использовать существующий чистый checkout
закреплённого коммита; по умолчанию создаётся bare clone и отдельный worktree
в `.build`. `ZAPRET_BUILD_PYTHON` задаёт интерпретатор сборки.
Для x86_64/universal нужны Python и бинарные зависимости с соответствующими
архитектурами; PyInstaller проверяет их и не подменяет целевую архитектуру.
Локально проверена сборка arm64.

## Проверки и диагностика

```sh
python3 -m unittest discover -s apps/zapret-local/telegram -p 'test_*.py'
python3 apps/zapret-local/telegram/test_bundle.py \
  "/Applications/Zapret Local.app/Contents/Resources/telegram/zapret-telegram"
```

`proxy.log` содержит статусы транспорта и счётчики байтов, без содержимого
сообщений; локальный secret скрыт. Лог ограничен 2 MB с двумя архивами.
`launcher.log` содержит ошибки запуска. Все TCP-сокеты процесса моста должны
вести только на loopback; внешние соединения создаёт broker Zapret.

29 октября 2026 года через цепочку MTProto-мост → Zapret получены корректные
`resPQ` с проверкой nonce для DC1–5 и DC203. В Telegram Desktop локальный
MTProto-прокси показал `online`. Эта проверка не подтверждает звонки.

## Отключение

Выключи Zapret Local или заверши приложение. Его встроенный мост остановится
вместе с основным прокси. Для возврата Telegram к обычному подключению отключи
локальный MTProto-прокси в настройках самого Telegram.
