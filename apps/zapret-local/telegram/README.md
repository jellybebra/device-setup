# Telegram Desktop через Zapret Local

Telegram Desktop подключается к локальному MTProto-мосту. Его соединения с дата-центрами и ретрансляторами
проходят через SOCKS Zapret Local. При недоступном SOCKS мост не переключается на прямой выход или VPN.
Telegram Web, ссылки `t.me` и звонки требуют собственных маршрутов. [Транспорт](run.py) ·
[Интеграция с приложением](../swift/TelegramBridge.swift)

Для части дата-центров используются официальные WebSocket-соединения. Остальные могут требовать внешних
ретрансляторов из закреплённого списка upstream. Ретранслятор видит IP и метаданные соединения, содержимое
остаётся зашифрованным MTProto. Проверка сертификата и имени TLS включена.
[Исходный транспорт](https://github.com/Flowseal/tg-ws-proxy)

Мост запускается вместе с локальным прокси. При обновлении сохраняются локальный порт и секрет, чтобы
существующее подключение Telegram Desktop продолжило работать. Готовность локального порта подтверждает
запуск процесса. Для проверки пути до дата-центра нужен ответ MTProto с ожидаемым nonce.
