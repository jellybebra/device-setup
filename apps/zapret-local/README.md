# Zapret Local

Нативное SwiftUI-приложение для строки меню macOS с сетевым помощником на Rust: локальный SOCKS5-прокси с выбором стратегии обхода DPI и встроенным Telegram-мостом. Интерфейс — включение, порт, стратегия, IP-сети и запуск при входе в систему. Чёрно-белая иконка имеет прозрачный фон и адаптируется к светлой и тёмной строке меню.

## Установка

1. Скачайте DMG из GitHub Releases: `Zapret-Local_<версия>_aarch64.dmg` для Apple Silicon или `Zapret-Local_<версия>_x86_64.dmg` для Intel.
2. Перенесите **Zapret Local** в **Applications**, затем запустите.
3. При первом включении подтвердите установку сетевого помощника системным паролем macOS. Python, Homebrew и окно Терминала для работы не нужны.

Нужна macOS 14 или новее. Универсальный DMG содержит версии для Apple Silicon и Intel. Сборка пока без Developer ID и нотарификации Apple: если macOS заблокирует первый запуск, откройте **Системные настройки → Конфиденциальность и безопасность → Открыть всё равно** для этого приложения. Ad-hoc подпись проверяет целостность сборки, но не подтверждает издателя Apple.

## Использование

Откройте панель через иконку в строке меню и включите прокси. Панель использует системный SwiftUI `MenuBarExtra` в режиме `.window`: macOS управляет подсветкой иконки, расположением, фокусом и закрытием. После запуска приложение остаётся в строке меню, не открывая панель поверх текущей работы. По умолчанию он слушает `127.0.0.1:49946`; порт можно изменить в панели. Если порт уже занят прежним тестовым прокси, выберите другой свободный порт. После смены порта обновите адрес в клиенте.

В v2rayN добавьте локальный SOCKS-профиль, например:

```text
socks://127.0.0.1:49946#Zapret-Local
```

Направьте на этот профиль YouTube, Discord, Instagram и X/Twitter; остальные правила и выбранный VLESS остаются под управлением v2rayN. Приложение само не меняет настройки v2rayN, системного прокси или DNS и не отключает существующий TUN.

«Запускать при входе» управляет запуском приложения после входа в macOS. Приложение восстанавливает сохранённое состояние включения прокси. Закрытие маленькой панели оставляет приложение в строке меню; выход из приложения останавливает его прокси.

### Стратегии и смена сети

В меню доступны 21 стратегия из закреплённой macOS-сборки [Flowseal](https://github.com/Flowseal/zapret-mac-discord-youtube) и прежняя **Моя проверенная настройка**. Последняя сохраняет отдельные профили Instagram, X и YouTube; она используется по умолчанию при обновлении. У стратегий Flowseal можно выбрать IP-сети:

- **Cloudflare** — официальные IPv4-диапазоны Cloudflare плюс доменные списки Flowseal и Instagram/X.
- **Список Flowseal** — IPSet из закреплённого выпуска Flowseal плюс доменные списки.
- **Все IPv4** — IPSet для всех IPv4; остальные фильтры и исключения выбранной стратегии сохраняются.
- **Только домены** — без общего IPSet, с доменными списками стратегии.

Выбор немедленно перезапускает движок и встроенный Telegram-мост на прежних портах. v2rayN и Telegram перенастраивать не нужно. Выбор сохраняется после выхода. Если движок не запускается, приложение возвращает предыдущую настройку; успешный запуск сам по себе не доказывает доступность сайтов. После смены Wi-Fi или восстановления сети приложение пробует переподключиться каждые 10 секунд. Кнопка **Переподключить** делает это вручную.

### Веб-трафик без добавления каждого сайта

Из корня репозитория можно обновить существующий профиль маршрутизации v2rayN:

```sh
python3 update-v2rayn-zapret.py --general-web --check
python3 update-v2rayn-zapret.py --general-web
```

Скрипт проверяет конфигурацию установленным Xray, сохраняет резервную копию и меняет только активные правила в БД v2rayN. После этого нажмите **Reload** в v2rayN. Явные исключения VPN/direct и локальные сети остаются выше общего веб-правила. Остальной TCP на портах 80, 443, 2053, 2083, 2087, 2096 и 8443 идёт через локальный Zapret; UDP/443 блокируется для перехода браузера на TCP. Общие списки `ru-blocked` остаются ниже этих правил для остального трафика. Выбранная стратегия решает, к каким соединениям применять обход DPI. Скрипт без `--general-web` обновляет только социальные маршруты.

Cloudflare обслуживает множество независимых сайтов. IPSet не обходит проверки Cloudflare, ограничения по стране или блокировку самого IP-адреса; результат зависит от провайдера и стратегии. Проверяйте полную загрузку изображений и видео, а не только открытие страницы.

## Сборка

Нужны macOS, Xcode Command Line Tools, Rust 1.90+ и Node.js 24. Все команды ниже выполняются из `apps/zapret-local`.

```sh
npm ci
cargo fetch --locked
npm run build
```

Сборка для обеих архитектур:

```sh
rustup target add aarch64-apple-darwin x86_64-apple-darwin
npm run build -- --target universal-apple-darwin
```

Результат: `.build/dist/Zapret-Local_<версия>_<архитектура>.dmg`, `SHA256SUMS.txt` и архив исходников включённого движка. Каноническая команда `npm run build` сначала собирает `.app`, обновляет контрольные суммы движка после подписи, проверяет пакет и создаёт DMG. Не распространяйте промежуточный `.app` до завершения этой команды.

Движок собирается из закреплённого коммита Flowseal `94c3b5125b4904ce2f6aec0e2197fe17f2fadf14`. Скрипт создаёт отдельный checkout в `.build`. Можно явно использовать уже подготовленный чистый worktree:

```sh
ZAPRET_ENGINE_CHECKOUT=/absolute/path/to/flowseal-worktree npm run build
```

Проверки без установки помощника и изменения сети:

```sh
cargo fmt --all -- --check
cargo test --locked --package zapret-core --package zapret-helper
```

Исходник иконки — `resources/icons/tray.svg`; PNG и ICNS воспроизводятся командой `swift scripts/generate-icons.swift`.

## Релиз

Workflow `.github/workflows/zapret-local-release.yml` запускается при push тега `zapret-vX.Y.Z` или вручную для уже существующего тега. Версия тега должна совпадать с `package.json` и workspace `Cargo.toml`. Apple Silicon и Intel собираются на отдельных нативных runners вместе со встроенным Telegram-мостом; релиз содержит два DMG и общий файл контрольных сумм.

GitHub Actions выполняет проверки, собирает универсальное приложение и публикует DMG, SHA-256 и точные исходники Flowseal в GitHub Release. Для нынешней сборки Apple-секреты не требуются. Публикация начинается только после отправки тега, а не при обычном push ветки.

## Устройство

Rust-прокси принимает SOCKS5 TCP CONNECT и UDP ASSOCIATE только на loopback. Исходящие сокеты, в том числе проверенный DoH, привязаны к физическому интерфейсу. Отдельное PF-правило направляет только трафик собственного broker UID и диапазона исходящих портов в частный utun движка. Общие правила PF, маршруты по умолчанию и чужие процессы не изменяются.

В прежней стратегии «Моя проверенная настройка» YouTube, Instagram и медиа X используют TCP `multidisorder`, сам `x.com` — TCP fake с 12 повторами, а Discord — TCP fake и UDP fake для Discord/STUN. Для файлов интерфейса `abs.twimg.com` и фотографий `pbs.twimg.com` DNS запрашивает `twimg.twitter.map.fastly.net`, для `video.twimg.com` — `dualstack.video.twitter.map.fastly.net`. Эти Fastly-серверы обслуживают исходные имена X; на другом CDN наблюдались обрывы JS и изображений после первых 15 КБ. IP берётся из DNS, исходные URL, SNI и проверка сертификата сохраняются. Поддерживаются публичные IPv4-назначения; это не VPN-сервер и не смена внешнего IP. Лицензии движка и зависимостей входят в пакет; см. [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Удаление

Выключите автозапуск и выйдите из приложения. Для удаления установленного сетевого помощника выполните:

```sh
sudo /Library/PrivilegedHelperTools/com.jellybebra.zapret-local/zapret-helper --uninstall
```

После этого удалите `Zapret Local.app` из Applications. Команда удаляет только собственный launchd-сервис, его сокет и установленный помощник.

## Telegram Desktop

Для Telegram используется [локальный MTProto → WebSocket-мост](telegram/README.md)
на базе Flowseal/tg-ws-proxy с исходящим транспортом через SOCKS Zapret Local.
Он входит в `.app` и DMG вместе с Python и зависимостями. Запускается и
останавливается вместе с Zapret Local; отдельной установки и автозапуска нет.
В общем блоке адресов можно менять порты Zapret и Telegram. Enter или галочка сохраняет порт; значок копирования копирует ссылку, стрелка ↗ справа от Telegram открывает подключение в Telegram Desktop. После изменения порта Telegram нажмите стрелку, чтобы обновить подключение клиента. Занятые порты и совпадение с портом Zapret отклоняются; секрет Telegram сохраняется.
