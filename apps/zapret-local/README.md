# Zapret Local

Локальный SOCKS5 для macOS 14 и новее. Трафик выбранных приложений выходит через физический интерфейс с
прежним внешним IP. Применяемая стратегия меняет обработку пакетов для обхода DPI. Интерфейс находится в
строке меню. SOCKS5 слушает только loopback. Помощник привязывает исходящие сокеты к физическому интерфейсу,
а правило PF отбирает пакеты по UID и исходным портам, чтобы обработка не затрагивала остальные приложения.
[Релизы для macOS](https://github.com/jellybebra/device-setup/releases) ·
[Лицензии компонентов](THIRD_PARTY_NOTICES.md)

## Стратегия и маршруты

Клиент решает, какой трафик направить в SOCKS. Стратегия и выбранный набор IP определяют, какие из этих
соединений получат обработку. Поэтому выбор «Все IPv4» в интерфейсе не переводит весь трафик компьютера в
прокси. [Стратегии](resources/strategies.json) · [Профили v2rayN](../../docs/v2rayn-routing.md)

Для медиа X выбор CDN существенен: на отдельных адресах страница открывалась, а загрузка JavaScript и
изображений обрывалась. Для поддерживаемых имён помощник может выбрать другой адрес CDN, сохраняя исходные
URL, имя TLS и проверку сертификата.

При пробуждении macOS приложение пересоздаёт локальный прокси и мост Telegram: процесс может остаться живым,
хотя старые сетевые соединения уже непригодны. Выключение прокси отменяет автоматическое восстановление.
Смена стратегии сохраняет порты клиентов. [Управление состоянием](swift/ProxyModel.swift) ·
[Мост Telegram Desktop](telegram/README.md)

## Совместимость выпуска

Выпуск включает сетевой помощник, движок и транспорт Telegram. На целевом Mac для работы приложения не
требуется отдельный Python или Homebrew. Сборка использует локальную ad-hoc подпись, без Developer ID и
нотарификации Apple. Версия в теге релиза должна совпадать с версиями в `package.json` и `Cargo.toml`.
[Процесс выпуска](../../.github/workflows/zapret-local-release.yml)
