# V2DPI

Приложение для macOS 14+ с переключателем в строке меню. ВКЛ запускает sing-box TUN, локальный DPI-помощник и Xray. ВЫКЛ освобождает туннель, временную запись DNS и маршруты приложения. Дома маршруты определяет Cudy. Для стендовой сборки используются отдельные идентификаторы приложения и помощника, настройки и локальные порты.

В меню «Управление серверами» можно добавить ссылку `vless://` (TCP с TLS или REALITY), переименовать сервер, заменить ссылку или удалить профиль. Приложение хранит список и выбранный сервер в закрытом файле `servers.json`. При чистой установке список пуст. Серверы видны прямо в главной панели: текущий отмечен круглым переключателем, для выбора другого нажмите на его строку. Если серверов больше восьми, список прокручивается. При включённом V2DPI приложение проверяет новый сервер через отдельный Xray перед переключением. Во время переключения у нового сервера отображается индикатор загрузки, а отметка выбора переносится только после успешной смены. При выключенном V2DPI отметка показывает сервер для следующего подключения; состояние доступно в подсказке при наведении. Чтобы удалить используемый сервер или заменить его ссылку, выберите другой сервер или выключите V2DPI. Telegram использует прозрачный маршрут к дата-центрам. Явный MTProto-прокси в настройках Telegram должен быть отключён.

Справа от каждого сервера отображается время HTTPS-запроса через его VLESS-соединение в миллисекундах. Вся строка высотой 32 pt выбирает сервер и подсвечивается целиком; отдельной кнопки у результата нет. До первой проверки отображается «—». Для обновления результатов нажмите «Проверить все» под списком. Проверки выполняются последовательно в отдельном Xray через физический интерфейс, не меняют выбранный профиль, TUN или системный DNS. Измеряется время HTTPS-запроса к `https://www.gstatic.com/generate_204`, включая установку соединения, но без запуска Xray: это не ICMP-пинг. При недоступности отображается «Ошибка» с подсказкой; при изменении ссылки или удалении профиля его результат сбрасывается.

Параметр `fastRetry` в JSON выбранного профиля сокращает ожидание начального TCP-подключения до двух секунд. После таймаута Xray использует свой штатный повтор с новым сокетом; работающие соединения и ожидание TLS не ограничиваются двумя секундами. Опция выключена по умолчанию, сохраняется между запусками и действует на подключение и проверки серверов. Изменение при включённом VPN переподключает его; при ошибке приложение восстанавливает прежнюю настройку и пытается вернуть соединение.


Правила охватывают IPv4. Обычные сайты выходят напрямую. YouTube, Discord, X, Instagram и Vercel используют DPI-помощник. Telegram, AI и Notion используют VLESS, даже если сайт размещён на Cloudflare. Остальной трафик на IPv4-адреса Cloudflare идёт напрямую: TCP на портах 80, 443 и 8443 и QUIC на UDP/443 проходят через DPI-помощник. Для Cloudflare Tunnel выделен прямой путь с DPI на порту 7844. DNS использует прямой DoH Cloudflare с повтором через Google, Google DNS через VLESS с ECS для выбора доступного CDN Meta и подстановки адресов Vercel. macOS получает локальный адрес и порт DNS. Перед регистрацией приложение проверяет ответ по UDP, адреса обоих прямых DoH исключены из захвата TUN. При ошибке запуска указывается этап проверки. Новые подключения к публичному IPv6 отклоняются в TUN.

Для IPv4-адресов Amazon CloudFront веб-трафик (TCP/80, TCP/443 и QUIC на UDP/443) проходит через выбранный VLESS-сервер. Явные маршруты сервисов выше по списку сохраняют приоритет. Файл `resources/cloudfront-ipv4.txt` содержит глобальные и региональные диапазоны из [списка AWS](https://d7uri8nf7uskq.cloudfront.net/tools/list-cloudfront-ips), обновлённого в сборке 10 ноября 2026 года.

Сокеты DPI-помощника привязаны к отдельному utun с адресом физического интерфейса и собственным маршрутом. macOS разбивает исходящий TCP-поток на сегменты до передачи в zapret. Это позволяет передавать большие TLS ClientHello при включённом аппаратном ускорении Wi-Fi.

Для TLS медиадоменов X (`twimg.com`) перед общим пресетом применяется отдельный профиль `multidisorder`: это предотвращает попадание картинок Fastly под нестабильный для них профиль `fake,multisplit` с перекрытием TCP-сегментов. Специальные правила Cloudflare сохраняют приоритет. UDP остаётся доступным; локальный SOCKS принимает неопределённый адрес `::` в запросе UDP ASSOCIATE от sing-box, сохраняя IPv4-транспорт и привязку UDP к локальному клиенту.

По умолчанию ресурсы GitHub (`githubassets.com` и поддомены) направляются напрямую. VLESS для них включается только явным правилом в профиле конкретной сети.

Для Instagram и его CDN приложение отклоняет UDP/443, чтобы браузер использовал прямой TCP через DPI-помощник. Для TLS-соединений помощник берёт имя из ClientHello и выбирает адрес через системный DNS V2DPI. Так браузер со старым адресом CDN также получает доступную точку, а проверка сертификата остаётся в браузере. Это правило относится к доменам `instagram.com` и `cdninstagram.com` и их поддоменам.

На macOS sing-box устанавливает свои стандартные IPv4-подсети начиная с `1.0.0.0/8`. Сеть `0.0.0.0/8` исключена: маршрут с нулевым адресом назначения может изменить выбор основного интерфейса Darwin. После запуска помощник проверяет одновременно системный маршрут в TUN и маршрут, привязанный к физическому интерфейсу.

При сбросе HTTPS помощник проверяет тот же IP через физический интерфейс. Если прямое соединение работает, он один раз повторяет запуск с TCP-стеком gVisor. Обе попытки используют одну политику маршрутизации. При неудаче помощник снимает захват трафика. Результаты проб, порты и события только этих соединений сохраняются локально в защищённом файле `last-https-failure.json` в каталоге установленного помощника.

## Проверка без переключения сети Mac

`npm run build` собирает приложение и DMG для текущей архитектуры. Нужны Xcode, Rust, Node и Go. Зависимости sing-box и Xray скачиваются по закреплённым версиям с проверкой SHA-256.

При уже работающем v2rayN и V2DPI можно проверить новый Xray, DNS, маршруты и обмен UDP через отдельные loopback-порты. Диагностика использует указанный действующий SOCKS DPI. Пример для Apple Silicon и интерфейса Wi-Fi:

```sh
python3 tests/loopback.py \
  --bin binaries/network-aarch64-apple-darwin \
  --interface en0 --dpi-port 49949 \
  --profile "$HOME/Library/Application Support/com.jellybebra.zapret-cudy/vless.json"
```

Полный тест выполняет ВКЛ/ВЫКЛ через установленный помощник. Он проверяет оба маршрута, системный DNS, новые HTTPS-соединения без прокси и восстановление после выключения. Запускайте его при выключенном TUN и с отдельным рабочим прокси для управления Mac. Для конфигурации, где v2rayN слушает порт 10808 и его VLESS-узел исключён из маршрутов V2DPI:

```sh
python3 tests/full_tun.py \
  --profile "$HOME/Library/Application Support/com.jellybebra.zapret-cudy/vless.json" \
  --management-proxy http://127.0.0.1:10808
```

Проверка системного ВКЛ/ВЫКЛ требует отдельного подключения для управления тестовым Mac. Переключение TUN прерывает текущие соединения. При активном чужом TUN приложение возвращает ошибку. Проверка через loopback не меняет DNS или маршруты macOS.

При уже включённом V2DPI можно проверить перемотку YouTube без изменения сети. Нужны модуль Node.js `playwright` и его отдельный Chrome for Testing. Команда `node tests/youtube-seek.cjs 'https://www.youtube.com/watch?v=VIDEO_ID' 1440p` открывает длинный ролик в новом временном профиле без системного прокси. Тест нажимает клавиши плеера для перехода на 60%, 90% и 20%, проверяет, что позиция была за пределами буфера, и ждёт новых медиаданных и воспроизведённых кадров. В конце он закрывает свой браузер. Без аргумента качества остаётся автоматическое качество плеера. Флаг `--watch` проверяет непрерывное воспроизведение первых 90 секунд вместо перемотки, отслеживая кадры, буфер и фактическое качество.

### Профили

Профиль выбирается вручную в компактном выпадающем списке «Профиль» в главном меню. Серверы остаются открытым списком без отдельного заголовка. Выбор сохраняется между запусками и не меняется при смене сети. В «Профили…» можно создать профиль с любым свободным названием, редактировать JSON, переименовать, создать независимую копию и удалить невыбранный профиль. Копии получают свободное имя с номером в скобках: «Работа (2)», «Работа (3)». Удаление требует подтверждения.

Профиль содержит `name`, `fastRetry`, `routing` (route sing-box), `dns` (dns sing-box), `dpiArguments` (аргументы utunws), `lists` (имя файла → содержимое). Параметр `fastRetry` задаётся только в JSON. Сервер, локальный порт и автозапуск общие для приложения; профили не содержат дату сохранения. VLESS-сервер выбирается в главном меню, локальный порт и автозапуск — в «Настройках…». Локальные файлы настроек имеют права 0600.

При переходе со старой версии Wi-Fi-профили однократно преобразуются в обычные независимые профили, их правила сохраняются целиком. Название сети и доступ к геопозиции больше не нужны. После миграции бывший профиль «По умолчанию» — обычный профиль, автоматического применения к новым сетям нет.

Правила, их порядок и маршрут по умолчанию задаёт пользователь. Для конфигураций с `custom` встроенные route/DNS/DPI заменяются полностью. Ссылки на списки и шаблоны пакетов используют `[списки]/имя.txt` и `[списки]/имя.bin`; свои текстовые списки включаются в `lists`, пакет можно задать hex-строкой в аргументе DPI. Локальный DNS `direct-doh` с адресом `127.0.0.1` без `server_port` получает служебный порт приложения при запуске. Системные интерфейсы, служебные процессы и выделяемые порты создаёт приложение.

Перед сохранением проверяются JSON, аргументы через `utunws --dry-run` и route/DNS через `sing-box check`. Ошибка проверки не прерывает подключение; ошибка активации возвращает прежний профиль. Переименование и создание копии не переподключают приложение. Снимок политики сверяется перед запуском: обновление движка не должно незаметно изменить сохранённые правила.

В «Настройках…» переключатель «Автозапуск» регистрирует основное приложение через `SMAppService.mainApp` для запуска при входе в macOS. Состояние читается из системы. При требуемом разрешении macOS появляется ссылка на системные настройки; отключение удаляет регистрацию автозапуска.
