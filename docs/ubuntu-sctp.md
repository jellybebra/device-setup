# Блокировка SCTP на тестовом сервере Ubuntu

19 ноября 2026 года на сервере и в контейнерах не было активных SCTP-сокетов. Чтобы закрыть путь к повышению привилегий через SCTP в цепочке NGINX2Root, в `/etc/modprobe.d/disable-sctp.conf` добавили два правила. [Рекомендация Xint](https://xint.io/blog/nginx2root-remote-code-execution)

```conf
blacklist sctp
install sctp /bin/false
```

После изменения обычный пользователь не смог открыть SCTP-сокет по IPv4 или IPv6. Модуль остался незагруженным. Перед возвратом SCTP следует подтвердить, что работающее ядро содержит исправление этой уязвимости, затем удалить файл блокировки.
