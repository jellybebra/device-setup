# Minecraft за домашним роутером

Проброс TCP/25565 на роутере и разрешение входящего соединения в Windows — две независимые настройки. При
двойном NAT маршрут должен проходить через оба роутера. При CGNAT одного домашнего проброса недостаточно.
UPnP может создать сопоставление на ближайшем шлюзе. Внешний IP и внутренний адрес должны по-прежнему
соответствовать работающему серверу.

На используемом Keenetic срок UPnP-сопоставления был нулевым (без истечения), но правило всё равно могло
исчезнуть при перезапуске. На ПК с v2rayN прямой проброс работал при включённом TUN и выключенном Strict
Route.

На Windows доступ ограничивается внешними IPv4 друзей. При изменении адреса провайдером исключение
устаревает. В схеме с явным запретом посторонних адресов списки разрешённых и заблокированных диапазонов
должны дополнять друг друга: пересечение блокирует и разрешённого игрока. IPv6 учитывается отдельно.
Проверка с другого компьютера в той же LAN не подтверждает доступность снаружи.
