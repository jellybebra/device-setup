# v2rayN: routing и TUN

Рабочий профиль macOS «RUv1-Заблокированное», сохранённый 27 сентября 2026 года. Формат правил подходит для v2rayN на macOS и Windows. Нужна своя подписка или настроенный proxy-сервер: адресов подключения, UUID и ключей в JSON нет.

**Для работы нужны два отдельных действия: импортировать правила и исключить IP самого proxy-сервера из TUN.** В проверенной конфигурации после добавления этого исключения на Mac снова заработала диктовка ChatGPT; на Windows ранее исчезли наблюдавшиеся сетевые обрывы.

## Импорт правил

1. Скачайте [routes.json](https://raw.githubusercontent.com/jellybebra/device-setup/main/configs/v2rayn/routes.json).
2. В v2rayN откройте настройки маршрутизации и создайте отдельный профиль, например **RUv1 — рабочий**. В его редакторе выберите **Импорт правил из файла** и укажите скачанный JSON. Создание нового профиля сохраняет старый для отката и исключает дублирование правил.
3. Установите стратегию доменов профиля **IPOnDemand**, сохраните и выберите этот профиль активным в главном окне.
4. Обновите GeoSite и GeoIP. Для категорий `ru-blocked` используются [базы runetfreedom](https://github.com/runetfreedom/russia-v2ray-rules-dat):

   ```text
   https://github.com/runetfreedom/russia-v2ray-rules-dat/releases/latest/download/geosite.dat
   https://github.com/runetfreedom/russia-v2ray-rules-dat/releases/latest/download/geoip.dat
   ```

   В поле шаблона источника Geo-файлов v2rayN используется `https://github.com/runetfreedom/russia-v2ray-rules-dat/releases/latest/download/{0}.dat`.
5. Настройте исключение TUN ниже и переподключите TUN.

Вместо файла можно импортировать содержимое JSON из буфера обмена или указать raw-ссылку в поле URL профиля и импортировать правила по URL. Названия пунктов зависят от версии и языка v2rayN; способы импорта описаны в [документации v2rayN](https://github.com/2dust/v2rayN/wiki/Description-of-some-ui).

## Обязательно: исключение proxy-сервера из TUN

В настройках TUN найдите **RouteExcludeAddress / исключённые адреса маршрутов** и добавьте внешний IP сервера в формате CIDR. Для текущего сервера:

```text
92.246.139.113/32
```

Для другого сервера укажите его IP: `/32` для отдельного IPv4 или `/128` для отдельного IPv6. Если сервер использует несколько адресов, добавьте каждый используемый адрес; после смены IP обновите исключение. Здесь нужен IP удалённого proxy-сервера, а не адрес компьютера в локальной сети.

Сохраните настройки, выключите и снова включите TUN. Это исключает транспортное соединение с самим сервером из перехвата TUN. Обычное правило `direct` внутри routing не заменяет это исключение.

Исключение хранится отдельно в `guiNConfig.json`, в `TunModeItem.RouteExcludeAddress`. **Файл `routes.json` его не содержит и при импорте не устанавливает.** Для проверки значения фрагмент выглядит так:

```json
{
  "TunModeItem": {
    "RouteExcludeAddress": ["92.246.139.113/32"]
  }
}
```

Это поясняющий фрагмент, а не полный конфиг для замены `guiNConfig.json`. Меняйте параметр через интерфейс v2rayN.

## Что направляется куда

Правила выполняются сверху вниз, порядок сохранён с рабочего Mac:

| № | Трафик | Действие |
| --- | --- | --- |
| 1 | BitTorrent | Напрямую |
| 2 | `geosite:category-ads-all` | Блокировать |
| 3–4 | Приватные сети и домены | Напрямую |
| 5 | DNS IP `1.0.0.1`, `1.1.1.1`, `8.8.8.8`, `8.8.4.4` | Через proxy |
| 6 | UDP-порты `19294–19344`, `50000–65535` для голоса Discord | Через proxy; правило применяется ко всем приложениям на этих портах |
| 7–8 | `geoip:ru-blocked`, `geosite:ru-blocked` | Через proxy |
| 9 | ChatGPT, OpenAI, ресурсы, авторизация и вспомогательные домены | Через proxy; полный список в JSON |
| 10 | Остальной трафик | Напрямую |

Отдельного правила `geosite:google` в текущем профиле Mac нет. Сайты Google и YouTube обрабатываются перечисленными правилами, включая `ru-blocked`; весь Google принудительно в proxy не направляется. В ранее настроенном Windows и в [профиле Happ для iPhone](happ-ios.md) отдельное правило Google есть.

## Параметры проверенной установки

| Параметр TUN | macOS | Windows |
| --- | --- | --- |
| Auto route | Включено | Включено |
| Strict route | Выключено | Выключено |
| Stack | `gvisor` | `mixed` |
| MTU | `9000` | `9000` |
| Legacy protect | Включено | Включено |
| IPv6 address | Выключено | Выключено |
| RouteExcludeAddress | IP proxy-сервера `/32` | IP proxy-сервера `/32` |

Это параметры наблюдавшихся рабочих установок, а не требование менять MTU или stack на каждом устройстве. На Windows Zapret остановлен, его автозапуск отключён; для этой конфигурации запускать его не требуется.

После настройки проверьте обычный запрос и Dictate в ChatGPT, затем голос Discord. Успешная загрузка сайта сама по себе не подтверждает работу диктовки или голосового соединения. Для отката выберите прежний профиль маршрутизации; исключение TUN управляется отдельно.

## Перенос из старого репозитория

Правила теперь находятся в [configs/v2rayn/routes.json](../configs/v2rayn/routes.json). Если использовали URL из `jellybebra/routing`, замените его на:

```text
https://raw.githubusercontent.com/jellybebra/device-setup/main/configs/v2rayn/routes.json
```

Перенесён текущий активный профиль Mac без локальных ID правил. Старые отключённые правила для Zapret, каталог `.idea` и `.gitignore` из отдельного репозитория не перенесены. Профиль Happ остаётся отдельным и этим JSON не заменяется.
