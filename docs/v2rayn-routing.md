# Клиентские профили v2rayN

Профили рассчитаны на v2rayN 7.24.9. В TUN трафик сначала обрабатывает sing-box. Правила процессов позволяют
выбрать маршрут для голосового соединения, даже если известно только приложение и IP собеседника.

| Базовый профиль | Google, YouTube и Discord | Источник |
| --- | --- | --- |
| Windows | Напрямую | [Правила TUN](../configs/v2rayn/windows/routes.json) · [Шаблон Xray](../configs/v2rayn/windows/xray-template.json) |
| macOS | Через прокси | [Правила TUN](../configs/v2rayn/macos/routes.json) · [Шаблон Xray](../configs/v2rayn/macos/xray-template.json) |

Адрес VPN-сервера исключается из TUN, чтобы соединение до самого сервера не вернулось в туннель. В публичных
шаблонах имя узла заменено на `vpn.example.com`. [Обновлятор Windows](../update-v2rayn.py) сохраняет домены
локального DNS-правила `direct-dns-1` или берёт имя из `V2RAYN_VPN_HOST`. При ручном импорте шаблона
требуется локальная подстановка.

**DNS и QUIC.** В настройках TUN для системного и удалённого DNS выбран DoH Cloudflare. В шаблонах Xray
включено распознавание QUIC: при соединении по IP браузер всё ещё может передать имя, нужное для выбора
маршрута. Проверка сайта по TCP не проверяет HTTP/3. Доступность голосового чата проверяется реальным
соединением с голосовым сервером.

## Cloudflare Tunnel

Клиентские профили отправляют порт `7844` через VLESS. `cloudflared` сам выбирает IP узла Cloudflare. При
подмене назначения по SNI Xray может потерять этот IP. Исключения нужны на каждом участке с такой подменой.
Если ПК использует прямой маршрут Cudy без локального TUN, серверная настройка на туннель не влияет.
[Сниффинг и серверные исключения](https://github.com/jellybebra/vless-docker#cloudflare-tunnel) ·
[Маршрут на Cudy](cudy-tr3000.md)

## Zapret Local на macOS

Это отдельный вариант для существующего профиля с локальным SOCKS. Полный шаблон Xray здесь выключен: иначе
его правила перекрывают изменения в Routing Setting. [Обновлятор маршрутов](../update-v2rayn-zapret.py)
сохраняет выбранный VPN и берёт локальный выход из правила Discord. Режим `--general-web` также направляет
общий веб-трафик в SOCKS после явных исключений.

Instagram и X используют TCP, потому что для их медиа работоспособность зависит от стратегии TLS и региона
CDN. Открывающаяся главная страница ещё не подтверждает загрузку фотографий и видео. Telegram Desktop
использует отдельный локальный MTProto-мост.
[Социальные маршруты](../configs/v2rayn/macos/zapret/social-routes.json) ·
[Zapret Local](../apps/zapret-local/README.md)

На Windows повышение приоритета sing-box частично уменьшало скачки пинга в Battlefield 6. Полностью
устранить их этим способом не удалось.
