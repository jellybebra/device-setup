# Приложения рабочего ПК с Windows

Первыми нужны Google Chrome, v2rayN, AMD Software: Adrenalin Edition и ChatGPT.

| Назначение | Приложения |
| --- | --- |
| Сеть | ZeroTier One |
| Общение и заметки | Discord с [Vencord](vencord.md), Telegram Desktop, Notion |
| Разработка | [Google Antigravity](https://antigravity.google/download), [Docker Desktop](https://www.docker.com/products/docker-desktop/) |
| Медиа и файлы | [mpv](https://mpv.io/installation/), OBS Studio, qBittorrent |
| Игры | [Xbox](https://www.xbox.com/en-US/apps/xbox-app-on-pc), Epic Games Launcher, Steam |

Яндекс Музыка используется как веб-приложение в Chrome.
