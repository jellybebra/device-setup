# YouTube на iPhone в Happ

1. Установите **Happ** по ссылке с [официального сайта](https://happ.info).
2. В ссылке своей подписки замените `/sub/` на `/happ/`:

   ```text
   https://example.com/sub/TOKEN
   https://example.com/happ/TOKEN
   ```

3. Скопируйте полученную ссылку и в Happ выберите **+ → Вставить из буфера**.
4. Выберите **Заблокированное + YouTube без рекламы** и включите VPN. При первом подключении разрешите добавление VPN-конфигурации.
5. Полностью закройте YouTube и откройте снова.

В этой же подписке есть вариант **Всё, кроме РФ**: российские домены и IP,
а также локальная сеть идут напрямую, остальное — через VPN, включая YouTube.
Вариант **Всё** направляет весь интернет через VPN, включая российские ресурсы;
локальная сеть остаётся напрямую. Вариант **Всё, кроме РФ + YouTube без рекламы**
оставляет РФ и локальную сеть напрямую, отправляет YouTube напрямую с прежней
TLS-фрагментацией, а остальные ресурсы — через VPN.

В обоих вариантах «YouTube без рекламы» YouTube работает по TCP:
UDP/443 блокируется с учётом прямых исключений. Это также затрагивает QUIC
других зарубежных сервисов. В вариантах **Всё** и **Всё, кроме РФ** такой
блокировки нет.

Для переключения выберите нужный вариант и переподключитесь. Если в подписке
несколько серверов, их исходные имена отображаются в описании вариантов.

Новые названия появляются после обновления сервиса подписок и самой подписки
в Happ. Дождитесь загрузки GeoSite/GeoIP перед подключением. Первый вариант
сохраняет прежнюю обработку YouTube с TLS-фрагментацией; переименование само
по себе не добавляет блокировщик рекламы.

Для входа по passkey с iPhone через QR на компьютере выключите **Xray TUN** в настройках Happ и переподключите VPN. Проверенная конфигурация и порядок обновления описаны в [инструкции passkey](passkeys-vpn.md).
