# Голосовой ввод в Chrome на Windows

## Проблема и обходное решение

В проверенной конфигурации Windows и Chrome **154.0.8037.58** отключение только автоматической регулировки громкости микрофона не устранило проблему распознавания голоса. Пользователь сообщил, что помогает запуск с отключением двух функций:

```text
--disable-features=ChromeWideEchoCancellation,WebRtcAllowInputVolumeAdjustment
```

Это обходное решение для конкретной проблемы с обработкой микрофона, а не универсальная настройка качества звука. Отдельно влияние каждой функции полностью не установлено. Отключение Chrome-wide echo cancellation не означает отключения всей аудиообработки или любого эхоподавления.

Чтобы не выбирать специальный ярлык `Chrome Voice`, эти параметры добавлены к обычным способам запуска Chrome для текущего пользователя:

| Способ запуска | Где настроено |
| --- | --- |
| Google Chrome в меню «Пуск» | `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Google Chrome.lnk` |
| Ссылки HTTP/HTTPS из других приложений | Значение по умолчанию в `HKEY_CURRENT_USER\Software\Classes\ChromeHTML\shell\open\command` |

Системный ярлык и файлы Chrome не изменялись. HTTP и HTTPS уже были назначены Chrome (`ChromeHTML`); браузер по умолчанию не менялся. Существующий закреплённый ярлык `Chrome Voice` уже содержал оба параметра и остался без изменений.

## Почему не chrome://flags

`Allow WebRTC to adjust the input volume` в этой конфигурации уже был установлен в **Disabled** на странице:

```text
chrome://flags/#enable-webrtc-allow-input-volume-adjustment
```

Этого оказалось недостаточно. Переключатель `Chrome-wide echo cancellation` в Chrome 154 отсутствовал: в метаданных этой версии его `expiry_milestone` равен `150`. Поэтому наличие функции в исходном коде ещё не означает доступность переключателя в `chrome://flags`. Добавлять отсутствующий флаг вручную в `Local State` как способ решения не проверялось.

## Как повторить настройку

Инструкция ниже соответствует установленному Chrome по пути `C:\Program Files\Google\Chrome\Application\chrome.exe`. Если путь другой, замените его в обеих настройках.

### 1. Обычный Chrome в «Пуске»

1. Через **Win+R → `shell:common programs`** откройте папку общих ярлыков. Найдите `Google Chrome`.
2. Через **Win+R → `shell:programs`** откройте папку ярлыков текущего пользователя. Если `Google Chrome.lnk` уже есть, сохраните его копию для отката и проверьте существующие параметры. Иначе скопируйте сюда общий ярлык. Общий ярлык оставьте без изменений.
3. В свойствах пользовательского ярлыка установите поле **Объект**:

   ```text
   "C:\Program Files\Google\Chrome\Application\chrome.exe" --disable-features=ChromeWideEchoCancellation,WebRtcAllowInputVolumeAdjustment
   ```

Эта команда рассчитана на обычный ярлык без дополнительных аргументов. Если у ярлыка есть параметры профиля, прокси или другие настройки, сохраните их. При существующем `--disable-features` дополните его список через запятую, а не создавайте второй такой аргумент.

### 2. Ссылки из других приложений

В проверенной конфигурации Windows использует `ChromeHTML` для HTTP и HTTPS. Назначение можно посмотреть в PowerShell:

```powershell
Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\Shell\Associations\UrlAssociations\http\UserChoice' | Select-Object ProgId
Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\Shell\Associations\UrlAssociations\https\UserChoice' | Select-Object ProgId
```

Если там другой идентификатор, эта инструкция не подтверждает, что изменение `ChromeHTML` затронет открытие ссылок. При необходимости выберите Google Chrome в стандартных настройках приложений Windows; вручную `UserChoice` не редактируйте.

Откройте `regedit` и перейдите к:

```text
HKEY_CURRENT_USER\Software\Classes\ChromeHTML\shell\open\command
```

Если ключ уже существует, сначала экспортируйте его через **Файл → Экспорт** и сохраните исходное значение по умолчанию. Если отсутствует, отметьте это для отката и создайте недостающие ключи. В проверенной конфигурации пользовательского переопределения не было; действовала системная команда:

```text
"C:\Program Files\Google\Chrome\Application\chrome.exe" --single-argument %1
```

Для строки **(По умолчанию)** типа `REG_SZ` задайте:

```text
"C:\Program Files\Google\Chrome\Application\chrome.exe" --disable-features=ChromeWideEchoCancellation,WebRtcAllowInputVolumeAdjustment --single-argument %1
```

Параметры функций должны находиться **до** `--single-argument %1`; часть для передачи ссылки сохраняется. Если исходная команда отличается от указанной, сначала разберитесь с её параметрами, не заменяйте их вслепую. Изменение в `HKEY_CURRENT_USER` применяется к текущему пользователю и не требует редактирования системного `HKEY_LOCAL_MACHINE`.

## Проверка

1. Сохраните незавершённую работу в браузере и полностью выйдите из Chrome через **⋮ → Выход**. Убедитесь в диспетчере задач, что процессов `chrome.exe` не осталось. Если мешают фоновые приложения, отключите их работу после закрытия Chrome в **Настройки → Система**.
2. Запустите обычный **Google Chrome** из «Пуска» и откройте `chrome://version`.
3. В строке **Командная строка / Command Line** найдите `--disable-features` и обе функции: `ChromeWideEchoCancellation` и `WebRtcAllowInputVolumeAdjustment`.
4. Повторите полный выход, откройте HTTPS-ссылку из другого приложения и снова проверьте `chrome://version`. Это отдельно проверяет обработчик ссылок.
5. Проверьте распознавание голоса с тем же микрофоном и на том же сайте.

При настройке 26 сентября 2026 года проверены сохранённые параметры ярлыка и команда HTTP/HTTPS через Windows API `AssocQueryString`. В уже работающем процессе Chrome также присутствовал параметр отключения эхоподавления. Повторная проверка качества голоса после изменения способов запуска на момент записи не подтверждена.

## Ограничения

- Это настройка способов запуска, а не глобальная настройка Chrome. Прямой запуск `chrome.exe` без параметров, другие ярлыки, приложения с собственным запуском браузера и отдельные профили могут её обходить.
- Уже запущенный Chrome не применяет новые параметры только от открытия ещё одного окна. Для проверки нужен полный выход; кнопка Relaunch может сохранить параметры предыдущего запуска.
- Настройка `ChromeHTML` касается приложений, использующих ассоциации Windows. Она не меняет запуск отдельного приложения ChatGPT или `ChatGPT Proxy`.
- Обновления Chrome могут изменить поддержку функций или регистрацию способов запуска. При возвращении проблемы повторите проверку через `chrome://version`.

## Откат

1. Полностью закройте Chrome.
2. Если пользовательский `Google Chrome.lnk` существовал до настройки, восстановите его резервную копию. Если он был создан этой настройкой, удалите только этот пользовательский ярлык: общий ярлык в «Пуске» оставлен без изменений.
3. Если пользовательское значение `ChromeHTML\shell\open\command` существовало, восстановите его из резервной копии. Если оно было создано этой настройкой, удалите только добавленное значение по умолчанию; пустой ключ `command` можно удалить. Системная команда снова будет использоваться через объединённое представление `HKEY_CLASSES_ROOT`. Не удаляйте целиком `ChromeHTML` или чужие значения. Если настройку с тех пор меняли, сначала сравните текущее содержимое с резервной копией.
4. Перезапустите Chrome обычным способом и проверьте `chrome://version`. Ярлык `Chrome Voice` при его использовании всё ещё передаёт параметры; его можно удалить отдельно. Ранее вручную отключённая регулировка громкости в `chrome://flags` остаётся отключённой; при необходимости верните её в **Default**.
