# Голосовой ввод в Chrome на Windows

В Chrome 154 одного отключения автоматической регулировки громкости оказалось недостаточно для распознавания
речи на проверенном микрофоне. Рабочее сочетание параметров запуска:

```text
--disable-features=ChromeWideEchoCancellation,WebRtcAllowInputVolumeAdjustment
```

Выбор двух функций относится к этому обходному решению. Отдельный эффект каждой функции не установлен. В
Chrome 154 переключателя Chrome-wide echo cancellation в `chrome://flags` уже не было.

Параметры нужны и в пользовательском ярлыке меню «Пуск», и в обработчике HTTP/HTTPS `ChromeHTML`. Иначе
запуск по ссылке может дать другое поведение. Обработчик должен сохранить передачу URL через
`--single-argument %1`. Уже работающий процесс Chrome сохраняет старую командную строку. Фактические
параметры видны в `chrome://version` после полного выхода и нового запуска.
