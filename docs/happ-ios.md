# Happ на iOS

Для настройки YouTube в приложении выполните [эту инструкцию](happ-youtube-dpi.md).

Для входа по passkey через QR с включённым VPN выполните [инструкцию проверки](passkeys-vpn.md).

## Быстрая настройка

1. Добавьте свою подписку или `vless://…` через **+ → Вставить из буфера обмена**. Если сервер уже есть в Happ, используйте его.
2. Откройте [готовую ссылку маршрутизации](https://raw.githubusercontent.com/jellybebra/device-setup/main/configs/happ/routing-link.txt) и скопируйте **всё содержимое страницы**: одну строку, начинающуюся с `happ://routing/onadd/`. Копировать нужно саму строку, а не адрес страницы.
3. Вернитесь в Happ и выберите импорт из буфера обмена в меню **+**. Должен появиться профиль **v2rayN - iPhone**.
4. **У нужной подписки на главном экране** откройте **⋯ → Routing / Маршрутизация**. Если импортированный профиль находится только в разделе **SERVER-LIST**, выберите **⋯ → Copy from / Копировать из → v2rayN - iPhone**. Затем выберите кружок рядом с этим профилем в своей подписке и включите маршрутизацию.
5. В настройках Geo-файлов обновите **GeoSite** и **GeoIP**. Ссылки на базы уже включены в профиль. Дождитесь окончания обеих загрузок и включите **Truncate geo files / Обрезать Geo-файлы**, если этот переключатель доступен. В профиле также установлен `UseChunkFiles: "true"`.

## Не работал Brawl Stars

Добавил правило `geosite:supercell` через VPN и В JSON-подписке
`/happ/` TCP/UDP на порт назначения `9339` также отправляется через VPN, даже
если соединение содержит только IP. Это правило находится внутри JSON-конфигурации сервера, а не в `routing-link.txt`.

# YouTube на iPhone в Happ

1. Установите **Happ** по ссылке с [официального сайта](https://happ.info).
2. В ссылке своей подписки замените `/sub/` на `/happ/`:

   ```text
   https://example.com/sub/TOKEN
   https://example.com/happ/TOKEN
   ```

3. Скопируйте полученную ссылку и в Happ выберите **+ → Вставить из буфера**.
4. Выберите **Заблокированное + YouTube без рекламы** и включите VPN. При первом подключении разрешите добавление VPN-конфигурации.

Для входа по passkey с iPhone через QR на компьютере выключите **Xray TUN** в настройках Happ и переподключите VPN. Проверенная конфигурация и порядок обновления описаны в [инструкции passkey](passkeys-vpn.md).
