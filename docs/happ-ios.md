# Happ на iOS

Для настройки YouTube в приложении выполните [эту инструкцию](happ-youtube-dpi.md).

Для входа по passkey через QR с включённым VPN выполните [инструкцию проверки](passkeys-vpn.md).

## Быстрая настройка

1. Установите **Happ** по ссылке с [официального сайта](https://happ.info).
2. Добавьте свою подписку или `vless://…` через **+ → Вставить из буфера обмена**. Если сервер уже есть в Happ, используйте его.
3. Откройте [готовую ссылку маршрутизации](https://raw.githubusercontent.com/jellybebra/device-setup/main/configs/happ/routing-link.txt) и скопируйте **всё содержимое страницы**: одну строку, начинающуюся с `happ://routing/onadd/`. Копировать нужно саму строку, а не адрес страницы.
4. Вернитесь в Happ и выберите импорт из буфера обмена в меню **+**. Должен появиться профиль **v2rayN - iPhone**.
5. **У нужной подписки на главном экране** откройте **⋯ → Routing / Маршрутизация**. Если импортированный профиль находится только в разделе **SERVER-LIST**, выберите **⋯ → Copy from / Копировать из → v2rayN - iPhone**. Затем выберите кружок рядом с этим профилем в своей подписке и включите маршрутизацию.
6. В настройках Geo-файлов обновите **GeoSite** и **GeoIP**. Ссылки на базы уже включены в профиль. Дождитесь окончания обеих загрузок и включите **Truncate geo files / Обрезать Geo-файлы**, если этот переключатель доступен. В профиле также установлен `UseChunkFiles: "true"`.

## Brawl Stars не подключается (Android / iOS)

Профиль использует VPN выборочно. Правило `geosite:supercell` отправляет домены
Supercell, включая Brawl Stars и Supercell ID, через VPN. Список доменов берётся
из [GeoSite](https://github.com/v2fly/domain-list-community/blob/master/data/supercell).

Одного доменного правила недостаточно для игрового протокола. В JSON-подписке
`/happ/` TCP/UDP на порт назначения `9339` также отправляется через VPN, даже
если соединение содержит только IP. Локальные адреса остаются прямыми;
другие приложения на том же внешнем порту тоже используют VPN. Это правило
находится внутри JSON-конфигурации сервера, а не в `routing-link.txt`.

После публикации обновлённого профиля повторно импортируйте готовую ссылку
маршрутизации и выберите профиль у своей подписки. Для подписки `/happ/` после
обновления сервиса на сервере обновите подписку в Happ. Обновите GeoSite,
переподключите VPN и полностью перезапустите игру.

Если игра всё ещё не работает, проверьте её с направлением всего трафика через
VPN. На Android также убедитесь, что Brawl Stars не исключена из VPN настройками
маршрутизации приложений. Если полный туннель помогает, нужно проверить
маршруты игровых соединений: обращения к IP без доменного имени на других портах
могут не совпасть с правилами. Если не помогает и полный туннель, одного
доменного правила недостаточно — нужны ошибка игры и проверка выбранного сервера.
