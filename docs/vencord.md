# Vencord на Windows

После обновления Discord Stable может исчезнуть загрузчик Vencord. Встроенное обновление Vencord работает
только пока мод загружается, поэтому восстановление привязано к запуску Discord через закреплённый ярлык.

[Настройка ярлыка](../setup-vencord-launcher.ps1) сохраняет оригинал и размещает рабочую копию вне
репозитория. [Загрузчик](../vencord-launcher.cs) проверяет мод в начале сеанса и учитывает замену файлов в
первую минуту работы. Постоянная служба для этого не нужна. Нажатие на значок уже открытого Discord может
только переключить окно и не запустить проверку.

При восстановлении установщик может закрыть Discord, что прервёт текущий звонок. Исправная установка
продолжает запускаться без загрузок. [Установщик](../install-vencord.ps1)
