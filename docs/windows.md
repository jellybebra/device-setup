# Windows и приложения Xbox

Ошибки системных файлов Windows и ошибки доступа приложений Xbox требуют разных проверок. В первом случае
имеют значение целостность системы и хранилище компонентов. Во втором — эффективные разрешения приложения в
профиле пользователя. Изменение прав всего дерева `%LOCALAPPDATA%\Packages` затрагивает и другие приложения,
поэтому такую операцию нельзя считать универсальным исправлением Xbox.
