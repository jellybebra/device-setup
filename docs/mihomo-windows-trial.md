# Clash Verge / Mihomo в Windows

Текущая схема с 17 октября 2026: прямой VLESS Reality, два адреса одного сервера.

| Группа «VPN — выход в интернет» | Адрес | Назначение |
| --- | --- | --- |
| Мой сервер · VLESS | 92.246.139.113:443 | Основное подключение |
| Мой сервер · VLESS · 138.124.114.237 | 138.124.114.237:443 | Запасной адрес, выбирается вручную |

Ключи и TLS server name у обоих узлов одинаковые. Адреса заданы явно, чтобы
подключение к серверу не зависело от отдельного DNS bootstrap. Старых
переключателей транспорта и дополнительных промежуточных туннелей нет.
[Короткая таблица сравнения](vpn-comparison.md).

## Рабочие настройки

- Clash Verge Rev 2.5.8, Mihomo 1.19.32; режим Rule.
- Локальный HTTP/SOCKS-прокси: `127.0.0.1:7897`.
- На момент очистки TUN выключен; его состояние и настройка System Proxy не менялись.
- VPN-группа влияет только на трафик, направленный в неё правилами. Google/YouTube
  и Discord остаются DIRECT через zapret; порядок правил сохранён.
- DNS для VPN направляется через выбранный VLESS. Прямые DNS и правила исключений
  сохранены. Локальные providers `ru-blocked` лежат в каталоге Clash
  `rule-providers/device-setup`; не заменять их встроенными DAT без этой категории.
- Auto Launch и Silent Start управляются штатными настройками Clash.
- Для zapret general (EXP) ранее проверена необходимость TCP timestamps enabled.
  Настройки zapret и приоритет ядра этой очисткой не менялись.

После применения проверены Telegram и YouTube (HTTP 200), API OpenAI (HTTP 401
без ключа). В API и интерфейсе Clash — только два VLESS-узла, выбран основной.

## Построение нового профиля

Из приватного Xray-конфига импортируется только outbound `proxy` с VLESS Reality.
Приватные ключи и UUID не хранить в Git.

```powershell
python .\mihomo\build_profile.py --vless-xray-config 'C:\private\xray.json' --geodata-dir 'C:\private\geodata' --output 'C:\private\clash\device-setup.yaml'
```

Каталог результата должен уже существовать с приватными правами. Для импорта
скопировать созданный профиль и `rule-providers/device-setup` в каталог Clash.
Генератор отказывается перезаписывать существующий профиль; TUN нового профиля
по умолчанию выключен. Адреса можно задать через `--primary-ip` и `--alternate-ip`.

Проверки генератора и правил:

```powershell
python -m unittest discover -s mihomo -p 'test_*.py'
```

Отдельная [история локальных задержек игровых пакетов TUN](battlefield-latency-20261013.md)
не означает, что смена VPN-протокола устранила эти задержки.
