# Battlefield 6, 13 октября 2026

[Описание метода, выводы и повторение](../../../docs/battlefield-latency-20261013.md).

- `baseline-analysis.json`: 120 с при исходном AboveNormal, до просьбы включить 60 FPS.
- `cap60-analysis.json`: 120 с после подтверждения пользователем лимита 60 FPS; фактический FPS не записывался.
- `priority-analysis.json`: 150 с, AboveNormal → High → AboveNormal.
- `priority-phases.jsonl`: реальные времена переключений и восстановления.
- `control-probes.json`: STUN через физический интерфейс и обычный маршрут через TUN, загрузка CPU.
- `isolated-stacks-partial.json`: отдельные mixed/system без default route; третья фаза gvisor не завершилась, её результата нет.
- `isolated-stacks-cleanup.json`: независимая проверка отсутствия тестовых адаптеров, маршрутов и процессов после частичного теста.
- `system-tun-idle.json`: успешный запуск основного TUN system, 15 секунд без игры.
- `system-tun-probes.json`: 120 секунд контрольных STUN/CPU с основным system; матч закончился в начале серии.
- `system-tun-kernel.json`: метки ядра той же серии, отдельно устойчивый фокус. Включает экран после матча; не считать полноценным игровым сравнением.
- `system-game-mode-off-kernel.json`, `system-game-mode-off-probes.json`: system после выключения игрового режима и перезапуска Battlefield; локальные задержки сохранились. Пользователь за индикатором не следил.
- `scheduler-attempt.json`, `scheduler-game-closed.json`: отказ WPR при работающей игре и успешная короткая запись после её закрытия; причина отказа не установлена.
- `cpu-load-kernel.json`, `cpu-load-probes.json`, `cpu-load-scheduler.json`, `cpu-load-phases.jsonl`: CPU-only нагрузка без Battlefield. Большие локальные задержки не воспроизведены; этот тест не имитирует всю нагрузку игры.

Показатели `*_ms` в анализе захватов — задержка **внутри компьютера**, между двумя копиями одного UDP-пакета. Это не ping игрового сервера. `over50` — число пар с задержкой больше 50 мс. p95/p99 вычисляются по nearest rank; медиана — обычная статистическая медиана.

SHA-256 полного UDP payload используется только для однозначного сопоставления. Ключи с повторяющимися копиями исключены из пар. Часть несопоставленных наблюдений — намеренно прямые контрольные STUN-запросы, у которых не должно быть копии в TUN. Прочие несопоставленные записи не доказывают потери игры. Полные захваты и хеши в репозиторий не добавлены.
