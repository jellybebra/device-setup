# Измерения 13 октября 2026

Сеть пользователя в России → сервер test → публичные тестовые назначения. Замеры выполнены без Battlefield. Это снимок состояния сети, а не гарантия постоянной скорости.

- `idle-results.json`, `idle-summary.json`: первая серия сравнения прямого VLESS и WARP L4 → VLESS; 30 TCP-соединений на каждый путь, HTTPS и загрузки.
- `realping-like.json`: два последовательных запроса одним curl-процессом; сравнение минимума из двух приближено к Real delay v2rayN, но использует другой HTTP-клиент.
- `wireguard-comparison.json`: попеременное сравнение четырёх вариантов. По 40 UDP-запросов, 12 пар HTTPS-запросов и три загрузки 10 МБ на профиль; итог находится в `summary`.
- `wireguard-udp-repeat.json`: дополнительная попеременная серия, по 100 UDP-запросов для WARP → VLESS и WARP → WireGuard.
- `wireguard-service-checks.json`: Cloudflare trace на домене ChatGPT и ответы API OpenAI на запрос без авторизации. Это не проверка входа в аккаунт.

UDP-задержка измерена по ответу DNS 8.8.8.8 через SOCKS UDP ASSOCIATE; это не ICMP ping и не измерение игрового сервера. Скорость загрузки включает время запроса. В WARP → VLESS usque работает в режиме L4; для WireGuard используется UDP-совместимый режим и локальный релей. Результаты относятся к этим конкретным реализациям.

Конфиги с ключами и токенами в репозиторий не включены. Подготовка повторного эксперимента описана в [инструкции](../../../docs/warp-windows.md).
